# PeptiBloom

Monorepo de PeptiBloom.

Arquitectura prevista:

- Biblioteca científica pública: Astro + TypeScript
- Aplicación operativa: Ionic + Angular + Capacitor
- Backend/API: Django + Django REST Framework
- Base de datos: PostgreSQL

## Entorno base

- Ubuntu 24.04 LTS sobre WSL2
- Node 22
- Python 3.12
- Django 5.2 LTS
- PostgreSQL 16

## Estado

M0 — Bootstrap reproducible en progreso.
