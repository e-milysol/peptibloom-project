# Scientific Inventory Handoff

Owner: SCIENTIFIC INVENTORY workstream

## Purpose

Research, classify and review source material before it becomes production scientific content.

## Evidence classes

PeptiBloom research must clearly distinguish:
- solid evidence;
- limited evidence;
- anecdotal experience.

Controversy and unverifiable data must be explicitly marked rather than normalized into certainty.

## Handoff rule

Scientific Inventory does not publish directly to the public web.

The expected flow is:

`Scientific Inventory -> Evidence review/representation -> production-ready scientific content -> WEB`

If WEB needs scientific content that has not completed this path, create a cross-domain request instead of supplying provisional copy as fact.
